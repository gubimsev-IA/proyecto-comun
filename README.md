## Quiero participar

1. Lee **[Cómo participar](COMO_PARTICIPAR.md)**: GitHub explicado desde cero, paso a paso.
2. Lee **[Cómo nos organizamos](ORGANIZACION.md)**: equipos, responsables y cómo se aprueban los cambios.
3. Crea tu ficha en la carpeta **[participantes](participantes/)**. Es tu primera aportación.
4. ¿Ya dominas GitHub? Echa un vistazo a los **[retos](RETOS.md)**.

## Qué hay en este repositorio

| Carpeta o archivo | Para qué sirve |
|---|---|
| `README.md` | Esta página: qué es el proyecto |
| `COMO_PARTICIPAR.md` | Guía de GitHub para quien no lo ha usado nunca |
| `ORGANIZACION.md` | Reglas de trabajo del grupo |
| `RETOS.md` | Tareas más avanzadas para quien ya domina GitHub |
| `AGENTS.md` | Instrucciones para las IA que usemos (Claude, Codex, ChatGPT…) |
| `participantes/` | Una ficha por persona |
| `equipos/` | Una carpeta por equipo, con su trabajo |
| `ideas/` | Ideas, lluvias de ideas y propuestas para el futuro |
