# Participantes

Una ficha por persona. Crear la tuya es tu primera aportación al proyecto.

**Cómo hacerla:** sigue el apartado 3 de [Cómo participar](../COMO_PARTICIPAR.md#3-tu-primera-aportación-tu-ficha-de-participante).

**Resumen:** copia [`_plantilla.md`](_plantilla.md), crea en esta carpeta un archivo llamado `nombre-apellido.md` (minúsculas, sin tildes ni espacios), pega la plantilla, rellénala y envíala a revisión.

Solo se modifica la ficha propia.
